# SmartPark 비즈니스 모델 문서

## 1. 문서 개요

### 1.1 문서 목적

본 문서는 SmartPark 서비스의 비즈니스 모델을 정의하기 위해 작성되었다.

SmartPark는 도심 및 주거 지역의 주차난 문제를 해결하기 위한 AI 기반 스마트 주차 서비스이다. 사용자의 현재 위치와 목적지를 기반으로 주변 주차 가능 공간을 탐색하고, 곧 비워질 주차 공간 정보, 개인 주차장 공유, NFC 기반 간편 결제, AI 기반 혼잡도 분석 기능을 제공한다.

본 문서는 SmartPark가 어떤 사용자에게 어떤 가치를 제공하고, 어떤 방식으로 수익을 창출하며, 향후 어떤 방향으로 확장할 수 있는지 정리한다. 또한 이후 요구사항 정의서, 서비스 시나리오, 소프트웨어 설계서, 발표 자료 작성의 근거로 활용한다.

## 2. 서비스 개요

### 2.1 서비스 정의

SmartPark는 주차 공간을 찾는 이용자와 유휴 주차 공간을 제공하는 공급자를 연결하는 AI 기반 스마트 주차 플랫폼이다.

기존 주차 서비스가 주로 주차장 위치 안내, 예약, 할인, 결제에 집중한다면, SmartPark는 다음 기능을 통해 실제 주차 가능성을 높이는 데 초점을 둔다.

| 핵심 기능                  | 설명                                                             |
| -------------------------- | ---------------------------------------------------------------- |
| 현재 위치 기반 주차장 조회 | 사용자의 현재 위치를 기준으로 주변 주차장을 지도와 목록으로 제공 |
| 목적지 기반 주차장 검색    | 목적지 주변 주차 공간을 사전에 탐색                              |
| 곧 비워질 자리 안내        | 출차 예정 시간이 등록된 주차 공간을 곧 이용 가능한 공간으로 표시 |
| 개인 주차장 공유           | 개인 또는 건물 소유자가 유휴 주차 공간을 등록하고 공유           |
| NFC 기반 간편 결제         | NFC 태그를 활용해 이용 시작, 종료, 결제 흐름을 간소화            |
| AI 혼잡도 분석             | 시간대, 지역 특성, 과거 이용 데이터를 기반으로 혼잡도 예측       |
| 관리자 운영 기능           | 등록 승인, 신고 처리, 결제 오류 관리, 운영 통계 확인             |

---

### 2.2 서비스 핵심 가치

SmartPark의 핵심 가치는 단순한 주차장 정보 제공이 아니라, 주차 문제를 이용자, 공급자, 관리자 관점에서 함께 해결하는 것이다.

| 대상                  | 핵심 가치                                                     |
| --------------------- | ------------------------------------------------------------- |
| 일반 운전자           | 실제 주차 가능성이 높은 공간을 빠르게 찾을 수 있다.           |
| 일정 기반 방문자      | 도착 예정 시간 기준으로 주차 가능성을 미리 확인할 수 있다.    |
| 개인 주차 공간 공급자 | 남는 주차 공간을 간편하게 공유하고 추가 수익을 얻을 수 있다.  |
| 상가/건물 관리자      | 유휴 주차 공간을 효율적으로 운영하고 정산할 수 있다.          |
| 서비스 운영자         | 등록 정보, 신고, 결제 오류, 통계를 체계적으로 관리할 수 있다. |

## 3. 문제 정의

### 3.1 시장 문제

도심, 대학가, 병원, 상가, 행사장 주변에서는 주차 수요가 높지만 주차 공간은 제한적이다. 사용자는 목적지에 도착한 뒤 주차장을 찾는 과정에서 많은 시간을 소비하고, 만차 주차장을 반복적으로 이동하는 불편을 겪는다.

동시에 개인 주택, 빌라, 소규모 건물, 상가 등에는 특정 시간대에 사용되지 않는 유휴 주차 공간이 존재한다. 그러나 이 공간을 외부 이용자에게 공유하기 위해서는 등록, 결제, 이용 시간 관리, 분쟁 처리 등의 부담이 발생한다.

---

### 3.2 사용자별 문제

| 사용자 유형      | 주요 문제                                                    |
| ---------------- | ------------------------------------------------------------ |
| 일반 운전자      | 주차장 위치는 알 수 있지만 실제 빈자리 여부를 알기 어렵다.   |
| 일정 기반 방문자 | 병원, 회의, 공연 등 정해진 시간에 늦을 위험이 있다.          |
| 개인 공급자      | 유휴 주차 공간을 수익화하고 싶지만 관리와 분쟁이 부담스럽다. |
| 상가 관리자      | 시간대별 이용률 파악, 무단 주차 관리, 정산 관리가 어렵다.    |
| 운영 관리자      | 허위 등록, 신고, 결제 오류, 데이터 정확성 관리가 필요하다.   |

---

### 3.3 기존 서비스의 한계

| 한계                         | 설명                                                                          |
| ---------------------------- | ----------------------------------------------------------------------------- |
| 실시간 주차 가능성 판단 한계 | 주차장 위치 정보는 제공하지만 실제 도착 시점의 주차 가능성을 보장하기 어렵다. |
| 곧 비워질 자리 정보 부족     | 현재 만차인 공간이 언제 이용 가능해지는지 알기 어렵다.                        |
| 개인 유휴 공간 활용 부족     | 개인이나 소규모 건물의 주차 공간을 쉽게 공유하기 어렵다.                      |
| 소규모 주차장 인증 방식 부족 | 대형 관제 장비 없이 이용 시작과 종료를 기록하기 어렵다.                       |
| 운영 관리 기능 제한          | 신고, 승인, 정산, 결제 오류를 통합 관리하는 구조가 부족하다.                  |

## 4. 목표 시장

### 4.1 주요 시장

SmartPark의 목표 시장은 주차 공간 부족 문제가 자주 발생하는 지역과 유휴 주차 공간이 존재하는 지역이다.

| 시장             | 설명                                                            |
| ---------------- | --------------------------------------------------------------- |
| 도심 상권        | 강남, 성수, 홍대, 여의도 등 방문객이 많고 주차 수요가 높은 지역 |
| 대학가           | 수업, 행사, 상권 방문으로 주차 수요가 집중되는 지역             |
| 오피스 밀집 지역 | 출퇴근, 외근, 미팅으로 주차 수요가 많은 지역                    |
| 병원 주변        | 예약 시간 준수가 중요하고 주차 혼잡이 자주 발생하는 지역        |
| 상가/행사장 주변 | 특정 시간대에 주차 수요가 급증하는 지역                         |
| 주거 지역        | 개인 주차 공간 또는 빌라/주택 유휴 공간이 존재하는 지역         |

SmartPark의 초기 시장은 다음과 같이 설정한다.

| 우선순위 | 시장                  | 선정 이유                                                      |

## 7. 수익 모델

### 7.1 이용 건당 중개 수수료

SmartPark의 기본 수익 모델은 주차 이용 건당 중개 수수료이다. 사용자가 SmartPark를 통해 주차 공간을 이용하면, 결제 금액 중 일정 비율을 플랫폼 수수료로 부과한다.

| 항목      | 설명                                            |
| --------- | ----------------------------------------------- |
| 대상      | 개인 주차장, 상가 주차장, 제휴 주차장           |
| 과금 방식 | 주차 이용 금액의 일정 비율                      |
| 장점      | 이용이 발생할 때마다 수익이 발생한다.           |
| 고려사항  | 수수료가 과도하면 공급자 참여가 낮아질 수 있다. |

예시 구조는 다음과 같다.

```text
이용자 결제 금액 = 주차 이용 요금
공급자 정산 금액 = 주차 이용 요금 - 플랫폼 수수료
SmartPark 수익 = 플랫폼 수수료
```

---

### 7.2 결제 수수료 모델

NFC 기반 간편 결제 또는 앱 결제를 통해 결제 흐름을 제공하고, 결제 처리 과정에서 소액의 수수료를 확보할 수 있다.

| 항목      | 설명                                                     |
| --------- | -------------------------------------------------------- |
| 대상      | 앱 내 결제 이용 건                                       |
| 과금 방식 | 결제 금액의 일정 비율 또는 건당 수수료                   |
| 장점      | 결제 흐름이 플랫폼 안에서 이루어질수록 수익 추적이 쉽다. |
| 고려사항  | 결제 대행 수수료와 플랫폼 수수료를 구분해야 한다.        |

### 7.3 상위 노출 및 광고형 추천

공급자는 자신의 주차 공간을 검색 결과 상단에 노출하거나 추천 주차장으로 표시하기 위해 광고형 상품을 구매할 수 있다.

| 항목      | 설명                                                            |
| --------- | --------------------------------------------------------------- |
| 대상      | 개인 공급자, 상가 주차장, 민영 주차장                           |
| 과금 방식 | 기간제 광고, 클릭당 과금, 노출당 과금                           |
| 장점      | 공급자의 수요가 높은 지역에서 추가 수익을 창출할 수 있다.       |
| 고려사항  | 광고가 사용자 추천 품질을 훼손하지 않도록 표시 기준이 필요하다. |

광고형 추천은 반드시 일반 추천과 구분되어야 한다. 사용자는 광고 여부와 실제 혼잡도, 거리, 요금 정보를 함께 확인할 수 있어야 한다.

| 제공 기능 | 주차장 등록 관리, 이용 현황, 정산, 신고 관리, 혼잡도 통계 |
| 장점      | 반복적이고 안정적인 수익을 기대할 수 있다.                |

```text
사용자 주차장 검색
```

| 정산                | 신뢰 확보                 | 반복 공급자 확보        |

## 17. 발표용 요약

SmartPark의 비즈니스 모델은 주차 공간이 필요한 이용자와 유휴 주차 공간을 보유한 공급자를 연결하는 양면 플랫폼 구조이다.

이용자는 현재 위치와 목적지를 기반으로 주차장을 검색하고, AI 혼잡도 분석과 곧 비워질 자리 정보를 통해 실제 주차 가능성이 높은 공간을 선택할 수 있다. 공급자는 남는 주차 공간을 등록하고 이용 가능 시간과 요금을 설정하여 추가 수익을 얻을 수 있다.

SmartPark의 주요 수익 모델은 이용 건당 중개 수수료, NFC 기반 결제 수수료, 상위 노출 광고, B2B 구독형 주차 관리 서비스, 멤버십 모델이다. 초기에는 주차장 조회, 혼잡도 분석, 개인 주차장 등록, NFC 결제 기능을 중심으로 MVP를 구성하고, 이후 IoT 센서, 번호판 인식, 전기차 충전소 예약, B2B 주차 관리 솔루션으로 확장할 수 있다.

---

## 18. 정리

SmartPark는 단순한 주차장 검색 서비스가 아니라, 주차 공간 탐색, 주차 가능성 예측, 개인 주차장 공유, NFC 기반 결제, 관리자 운영 기능을 통합한 스마트 주차 플랫폼이다.

비즈니스 모델 측면에서 SmartPark는 이용자에게는 주차 탐색 시간 단축과 주차 성공 가능성 증가라는 가치를 제공하고, 공급자에게는 유휴 주차 공간 수익화 기회를 제공한다. 또한 상가, 병원, 학교, 기업 등 B2B 고객에게는 주차 운영 관리와 통계 기능을 제공하여 안정적인 구독 수익 모델로 확장할 수 있다.

따라서 SmartPark의 핵심 비즈니스 전략은 초기에는 특정 지역과 핵심 기능을 중심으로 MVP를 검증하고, 이후 공급자 확대, AI 추천 고도화, B2B 확장, 외부 데이터 연계를 통해 지속 가능한 스마트 주차 플랫폼으로 성장하는 것이다.
