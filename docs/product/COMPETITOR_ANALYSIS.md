# SmartPark 경쟁 서비스 분석 문서

## 1. 문서 개요

### 1.1 문서 목적

본 문서는 SmartPark와 유사한 주차 관련 서비스의 기능, 강점, 한계, 차별 요소를 비교 분석하기 위해 작성되었다.

SmartPark는 도심 및 주거 지역의 주차난 문제를 해결하기 위한 AI 기반 스마트 주차 서비스이다. 사용자의 현재 위치와 목적지를 기반으로 주변 주차 가능 공간을 탐색하고, 곧 비워질 주차 공간 정보, 개인 소유 주차장의 등록 및 공유, NFC 기반 간편 결제, AI 기반 혼잡도 분석 기능을 제공한다.

본 문서는 기존 주차 서비스와 SmartPark의 차이점을 정리하여 이후 요구사항 정의, 요구사항 분석, UI/UX 설계, 비즈니스 모델 수립의 근거로 활용한다.

## 2. SmartPark 서비스 포지션

### 2.1 SmartPark 핵심 정의

SmartPark는 단순히 주차장 위치를 안내하는 서비스가 아니라, 다음 기능을 통합한 스마트 주차 플랫폼이다.

| 핵심 기능                  | 설명                                                             |
| -------------------------- | ---------------------------------------------------------------- |
| 현재 위치 기반 주차장 조회 | 사용자의 현재 위치를 기준으로 주변 주차장을 지도와 목록으로 제공 |
| 목적지 기반 주차장 탐색    | 목적지 주변 주차장 정보를 사전에 확인                            |
| 곧 비워질 자리 안내        | 출차 예정 시간이 등록된 공간을 곧 이용 가능한 자리로 표시        |
| 개인 주차장 공유           | 개인 또는 건물 소유자가 유휴 주차 공간을 등록하고 공유           |
| NFC 기반 간편 결제         | NFC 태그를 활용하여 주차 이용 시작, 종료, 결제 흐름을 간소화     |
| AI 혼잡도 분석             | 시간대, 지역, 과거 이용 데이터 기반으로 주차장 혼잡도 예측       |
| 관리자 운영 기능           | 주차장 등록 승인, 신고, 결제 오류, 이용 내역 관리                |

---

### 2.2 SmartPark의 기본 경쟁 방향

SmartPark의 경쟁 방향은 다음과 같다.

```text
기존 서비스: 주차장 검색, 예약, 할인, 자동결제 중심
SmartPark: 주차 가능성 예측, 곧 비워질 자리, 개인 공유 주차장, NFC 이용 흐름, 운영 관리 통합
```

따라서 SmartPark는 기존 서비스와 직접 경쟁하기보다는, 기존 서비스가 충분히 해결하지 못한 주차 성공 가능성, 개인 유휴 공간 활용, 이용 시작/종료 인증, 공급자 관리 문제를 보완하는 방향으로 차별화한다.

## 3. 경쟁 서비스 개요

## 3.1 모두의주차장

### 3.1.1 서비스 개요

모두의주차장은 주차장 검색, 주차권 구매, 할인 주차권, 월정기권, 공유 주차장 기능을 제공하는 주차 플랫폼이다. 사용자는 목적지 주변 주차장을 검색하고, 주차권을 구매하거나 예약할 수 있다.

### 3.1.2 주요 기능

| 기능             | 설명                                       |
| ---------------- | ------------------------------------------ |
| 주변 주차장 검색 | 목적지 주변 주차장 위치와 가격 확인        |
| 주차권 구매      | 시간권, 일일권, 월정기권 등 주차 상품 구매 |
| 할인 주차권      | 제휴 주차장의 할인 상품 제공               |
| 공유 주차장      | 주차 공간 소유자와 이용자를 연결           |
| 지도 기반 탐색   | 지도 화면에서 주차장 위치 확인             |

### 3.1.3 강점

| 강점                | 설명                                                    |
| ------------------- | ------------------------------------------------------- |
| 높은 인지도         | 주차장 검색/할인 앱으로 인지도가 높다.                  |
| 주차권 상품화       | 시간권, 일일권, 월정기권 등 상품 구성이 명확하다.       |
| 공유 주차 개념 보유 | 주차 공간 소유자의 유휴 공간 활용 니즈를 일부 반영한다. |
| 가격 비교 용이      | 지도 기반으로 가격과 위치를 비교할 수 있다.             |

### 3.1.4 한계

| 한계                              | 설명                                                                                  |
| --------------------------------- | ------------------------------------------------------------------------------------- |
| 실시간 주차 성공 가능성 판단 한계 | 검색 결과가 실제 도착 시점의 주차 가능성을 완전히 보장하지는 않는다.                  |
| 곧 비워질 자리 정보 부족          | 현재 비어 있지 않더라도 곧 이용 가능한 공간을 예측하는 기능은 제한적이다.             |
| AI 혼잡도 기반 추천 약함          | 시간대, 지역 특성, 이용 패턴 기반의 예측 추천은 SmartPark의 차별 영역이 될 수 있다.   |
| 공급자 운영 관리 제한             | 개인 공급자가 이용 시간, 분쟁, 이용 인증을 정교하게 관리하는 기능은 보완 여지가 있다. |

## 3.2 카카오 T 주차

### 3.2.1 서비스 개요

카카오 T 주차는 카카오 T 앱 안에서 주차장 검색, 예약, 결제, 자동 정산을 제공하는 모빌리티 기반 주차 서비스이다. 카카오 T의 기존 이동 서비스와 연결되어 있어 사용자가 익숙한 앱 환경에서 주차 기능을 이용할 수 있다.

### 3.2.2 주요 기능

| 기능                    | 설명                                        |
| ----------------------- | ------------------------------------------- |
| 목적지 주변 주차장 검색 | 목적지 주변 주차장 정보 확인                |
| 주차장 예약             | 제휴 주차장 예약 가능                       |
| 자동 결제               | 등록된 결제 수단을 통한 자동 정산           |
| 주차 요금 확인          | 앱에서 주차 요금 확인                       |
| 일부 주차장 만차 예측   | 일부 제휴 주차장에 대해 만차 예측 정보 제공 |

### 3.2.3 강점

| 강점                 | 설명                                                        |
| -------------------- | ----------------------------------------------------------- |
| 강력한 플랫폼 접근성 | 카카오 T 사용자 기반을 활용할 수 있다.                      |
| 결제 편의성          | 자동 결제와 출차 정산 흐름이 편리하다.                      |
| 모빌리티 서비스 연계 | 택시, 대리, 내비게이션 등 이동 서비스와 연결 가능성이 높다. |
| 브랜드 신뢰도        | 대형 플랫폼 기반 서비스로 사용자 신뢰도가 높다.             |

### 3.2.4 한계

| 한계                         | 설명                                                                    |
| ---------------------------- | ----------------------------------------------------------------------- |
| 제휴 주차장 중심             | 서비스 제공 범위가 제휴 주차장에 상대적으로 의존할 수 있다.             |
| 개인 주차장 공유 기능 제한   | 개인 소유 주차장을 자유롭게 등록하고 공유하는 구조는 약하다.            |
| 곧 비워질 자리 정보 부족     | 이용자의 출차 예정 시간을 기반으로 한 곧 비워질 자리 안내는 제한적이다. |
| 지역 밀착형 공급자 관리 한계 | 소규모 개인 공급자나 상가 관리자 중심 기능은 상대적으로 약할 수 있다.   |

## 3.3 아이파킹

### 3.3.1 서비스 개요

아이파킹은 주차장 운영, 주차 관제, 모바일 주차 상품, 자동 결제 기능을 제공하는 주차 플랫폼이다. 운전자용 앱뿐 아니라 주차장 운영자를 위한 관리 기능도 함께 제공한다.

### 3.3.2 주요 기능

| 기능               | 설명                                    |
| ------------------ | --------------------------------------- |
| 주차장 검색        | 제휴 주차장 검색                        |
| 주차 상품 구매     | 주차권, 정기권 등 상품 구매             |
| 자동 결제          | 차량번호와 결제 수단 기반 간편 출차     |
| 주차장 운영 솔루션 | 주차장 관리자를 위한 운영 관리 기능     |
| 전기차 충전 정보   | 일부 서비스에서 전기차 충전소 정보 제공 |

### 3.3.3 강점

| 강점               | 설명                                                        |
| ------------------ | ----------------------------------------------------------- |
| 주차장 운영 인프라 | 주차 관제와 운영 시스템 기반이 강하다.                      |
| B2B 확장성         | 건물, 상가, 주차장 사업자 대상 운영 솔루션 제공이 가능하다. |
| 자동 결제 편의성   | 차량번호 기반 자동 결제와 논스톱 출차 경험을 제공한다.      |
| 운영 데이터 확보   | 주차장 운영 데이터를 바탕으로 서비스 품질 개선이 가능하다.  |

### 3.3.4 한계

| 한계                                | 설명                                                                                  |
| ----------------------------------- | ------------------------------------------------------------------------------------- |
| 관제 인프라 의존                    | 관제 장비와 제휴 주차장 중심으로 서비스 범위가 제한될 수 있다.                        |
| 개인 소규모 공급자 접근성 제한      | 개인 주차 공간을 간단히 등록하고 공유하는 구조는 상대적으로 약할 수 있다.             |
| 이용자 관점의 AI 추천 차별성 부족   | 단순 검색과 결제 외에 주차 성공 가능성 중심의 추천은 보완 여지가 있다.                |
| NFC 기반 개인 공간 인증과 차별 가능 | SmartPark는 별도 대형 관제 장비 없이 NFC 기반 이용 인증을 차별 요소로 활용할 수 있다. |

## 3.4 TMAP 주차

### 3.4.1 서비스 개요

TMAP 주차는 TMAP 앱 내에서 할인 주차장, 결제 가능 주차장 확인, 실시간 주차 요금 확인, 간편 결제, 논스톱 출차 흐름을 제공하는 주차 서비스이다. 내비게이션 서비스와 연결되어 주차장까지의 경로 안내에 강점이 있다.

### 3.4.2 주요 기능

| 기능                       | 설명                         |
| -------------------------- | ---------------------------- |
| 할인 주차장 확인           | 할인 가능한 주차장 확인      |
| TMAP 결제 가능 주차장 확인 | 앱 결제가 가능한 주차장 확인 |
| 실시간 주차 요금 확인      | 이용 중 주차 요금 확인       |
| 간편 결제                  | 앱 결제 또는 자동 결제       |
| 내비게이션 연동            | 선택한 주차장까지 경로 안내  |

### 3.4.3 강점

| 강점             | 설명                                                 |
| ---------------- | ---------------------------------------------------- |
| 내비게이션 연계  | 목적지 이동과 주차장 안내를 자연스럽게 연결한다.     |
| 운전자 접점 강함 | 운전 중 사용하는 앱이므로 주차 탐색과 연결되기 쉽다. |
| 결제 편의성      | 앱 결제와 자동 결제 흐름이 편리하다.                 |
| 실시간 요금 확인 | 주차 이용 중 요금을 확인할 수 있다.                  |

### 3.4.4 한계

| 한계                       | 설명                                                                           |
| -------------------------- | ------------------------------------------------------------------------------ |
| 내비게이션 중심 구조       | 서비스의 핵심은 이동 경로 안내이며, 공급자 등록/관리 기능은 상대적으로 약하다. |
| 개인 주차장 공유 기능 제한 | 개인 유휴 공간을 등록하고 공유하는 구조는 제한적이다.                          |
| 곧 비워질 자리 예측 부족   | 이용자 출차 예정 시간을 활용한 예측 정보는 SmartPark의 차별 영역이다.          |
| AI 혼잡도 추천 고도화 여지 | 도착 예정 시간과 과거 데이터 기반의 주차 성공 가능성 추천을 강화할 수 있다.    |

## 3.5 서울주차정보 및 공공 주차 정보 서비스

### 3.5.1 서비스 개요

서울주차정보와 같은 공공 주차 정보 서비스는 공영주차장과 일부 민영주차장의 위치, 운영 정보, 요금 정보, 실시간 주차 가능 정보를 제공한다. 공공 데이터를 기반으로 하기 때문에 정보의 공공성과 신뢰성이 장점이다.

### 3.5.2 주요 기능

| 기능                   | 설명                                         |
| ---------------------- | -------------------------------------------- |

# 6. SmartPark의 차별화 요소

## 6.1 차별화 요소 1: 곧 비워질 자리 안내

기존 서비스는 현재 주차장 정보와 예약 가능 여부를 중심으로 제공하는 경우가 많다. 그러나 실제 주차 상황에서는 “지금은 만차이지만 곧 비워질 공간”도 중요하다.

SmartPark는 현재 주차 중인 이용자가 출차 예정 시간을 입력하면 해당 공간을 곧 비워질 자리로 표시한다. 이를 통해 사용자는 현재 빈자리뿐 아니라 가까운 시간 안에 이용 가능한 공간까지 고려할 수 있다.

| 구분        | 기존 서비스                            | SmartPark                    |
| ----------- | -------------------------------------- | ---------------------------- |
| 제공 정보   | 현재 주차장 위치, 요금, 예약 가능 여부 | 현재 빈자리 + 곧 비워질 자리 |
| 사용자 가치 | 주변 주차장 탐색                       | 실제 주차 성공 가능성 증가   |
| 차별성      | 정적 정보 중심                         | 시간 기반 동적 정보 제공     |

---

## 6.2 차별화 요소 2: AI 기반 혼잡도 분석

SmartPark는 시간대, 지역 특성, 과거 이용 데이터, 도착 예정 시간 등을 기반으로 주차장 혼잡도를 예측한다.

단순히 가까운 주차장을 추천하는 것이 아니라, 사용자가 실제로 주차할 가능성이 높은 공간을 우선 추천한다.

| 구분        | 기존 서비스                   | SmartPark                                    |
| ----------- | ----------------------------- | -------------------------------------------- |
| 추천 기준   | 거리, 가격, 제휴 여부         | 거리 + 요금 + 예상 혼잡도 + 주차 성공 가능성 |
| 분석 방식   | 현재 정보 또는 제휴 정보 중심 | 과거 데이터와 시간대 기반 예측               |
| 사용자 가치 | 선택지 제공                   | 의사결정 지원                                |

---

## 6.3 차별화 요소 3: 개인 주차장 공유

SmartPark는 공영주차장과 민영주차장뿐 아니라 개인 소유 주차 공간을 등록하고 공유하는 기능을 포함한다.

개인 주택, 빌라, 소규모 건물, 상가의 유휴 주차 공간을 서비스에 등록할 수 있도록 하여, 주차 공간 공급을 확대할 수 있다.

| 구분      | 기존 서비스                        | SmartPark                         |
| --------- | ---------------------------------- | --------------------------------- |
| 공급 대상 | 제휴 주차장, 공영/민영 주차장 중심 | 공영, 민영, 개인 주차장 통합      |
| 공급자    | 주차장 사업자 중심                 | 개인, 상가, 건물 관리자까지 확장  |
| 수익 구조 | 주차권 판매/예약 수수료            | 공유 주차 중개 수수료 + 관리 기능 |

## 6.4 차별화 요소 4: NFC 기반 이용 시작/종료 및 결제

SmartPark는 NFC 태그를 통해 주차 이용 시작과 종료를 기록하고, 이용 시간을 기준으로 요금을 계산하는 흐름을 제공한다.

이는 고가의 주차 관제 장비를 설치하기 어려운 개인 주차 공간이나 소규모 주차장에서도 비교적 간단하게 이용 인증을 처리할 수 있는 방식이다.

| 구분      | 기존 서비스                              | SmartPark                        |
| --------- | ---------------------------------------- | -------------------------------- |
| 이용 인증 | 차량번호 인식, 예약 정보, 현장 결제 중심 | NFC 태그 기반 이용 시작/종료     |

## 6.5 차별화 요소 5: 공급자와 관리자 기능 강화

SmartPark는 이용자 앱뿐 아니라 공급자와 운영 관리자의 흐름도 함께 고려한다.

공급자는 주차 공간 등록, 이용 가능 시간 설정, 요금 설정, 이용 내역 확인, 정산 확인을 할 수 있다. 운영 관리자는 등록 승인, 신고 처리, 결제 오류 관리, 이용 내역 조회, 운영 통계를 확인할 수 있다.

| 관리자 기능 | 서비스 내부 중심 | 문서와 요구사항 단계에서 명확히 정의 |

# 15. 정리

경쟁 서비스 분석 결과, 기존 주차 서비스는 주차장 검색, 예약, 할인, 자동 결제, 지도 기반 경로 안내에 강점을 가지고 있다. 특히 대형 플랫폼은 사용자 접근성과 결제 편의성이 뛰어나며, 주차 관제 기반 서비스는 운영 인프라 측면에서 강점을 가진다.

그러나 여전히 실제 도착 시점의 주차 가능성, 곧 비워질 자리 정보, 개인 유휴 주차 공간의 간편한 등록과 공유, 소규모 주차장 이용 인증, 공급자와 관리자 중심의 운영 관리에는 개선 여지가 있다.

SmartPark는 이러한 한계를 보완하기 위해 AI 기반 혼잡도 분석, 곧 비워질 자리 안내, 개인 주차장 공유, NFC 기반 이용 시작/종료 및 결제, 관리자 운영 기능을 통합한 스마트 주차 플랫폼으로 차별화한다.

따라서 SmartPark의 경쟁 전략은 단순히 기존 주차 앱과 같은 기능을 제공하는 것이 아니라, 사용자가 실제로 주차할 가능성을 높이고, 공급자가 유휴 공간을 쉽게 공유하며, 관리자가 서비스 신뢰성을 유지할 수 있는 통합 구조를 만드는 데 초점을 두어야 한다.
