# SmartPark 서비스 시나리오 문서

## 1. 문서 개요

### 1.1 문서 목적

본 문서는 SmartPark 서비스가 실제 사용 상황에서 어떻게 동작하는지 구체적인 시나리오로 정리하기 위해 작성되었다.

SmartPark는 도심 및 주거 지역의 주차난 문제를 해결하기 위한 AI 기반 스마트 주차 서비스이다. 사용자의 현재 위치와 목적지를 기반으로 주변 주차 가능 공간을 탐색하고, 곧 비워질 주차 공간 정보, 개인 주차장 공유, NFC 기반 간편 결제, AI 기반 혼잡도 분석 기능을 제공한다.

본 문서는 `PERSONA.md`, `USER_JOURNEY.md`, `COMPETITOR_ANALYSIS.md`에서 정리한 사용자 유형, 이용 흐름, 경쟁 서비스 차별성을 바탕으로 실제 서비스 이용 상황을 시나리오 형태로 구체화한다.

---

## 2. 서비스 시나리오 작성 범위

SmartPark의 서비스 시나리오는 크게 세 가지 관점에서 작성한다.

| 구분            | 대상 사용자                               | 주요 목적                                             |
| --------------- | ----------------------------------------- | ----------------------------------------------------- |
| 이용자 시나리오 | 일반 운전자, 일정 기반 방문 운전자        | 주차 공간을 빠르고 정확하게 탐색하고 이용하는 과정    |
| 공급자 시나리오 | 개인 주차 공간 공급자, 상가 주차장 관리자 | 주차 공간을 등록, 운영, 정산하는 과정                 |
| 관리자 시나리오 | 서비스 운영 관리자                        | 등록 승인, 신고, 결제 오류, 운영 통계를 관리하는 과정 |

# 5. SS-01 도심 약속 장소 주변 주차장 탐색

## 5.1 시나리오 개요

| 항목          | 내용                                                               |
| ------------- | ------------------------------------------------------------------ |
| 시나리오 ID   | SS-01                                                              |
| 시나리오명    | 도심 약속 장소 주변 주차장 탐색                                    |
| 주요 Actor    | 일반 운전자                                                        |
| 관련 페르소나 | 김민준                                                             |
| 목적          | 도심 상권 주변에서 실제 주차 가능성이 높은 주차장을 빠르게 찾는다. |
| 핵심 기능     | 목적지 기반 주차장 검색, AI 혼잡도 분석, 주차장 상세 정보 제공     |

---

## 5.2 상황 설명

김민준은 주말 저녁 성수동에서 친구들과 약속이 있다. 성수동은 방문객이 많아 주차장이 빠르게 만차가 되는 지역이다. 김민준은 기존 지도 앱에서 주차장을 검색해본 적이 있지만, 도착했을 때 실제로 자리가 없어 다시 다른 주차장을 찾은 경험이 있다.

이번에는 SmartPark를 실행하여 목적지 주변의 주차 가능 공간과 예상 혼잡도를 미리 확인한다.

---

## 5.3 사전 조건

| 조건               | 설명                                                                 |
| ------------------ | -------------------------------------------------------------------- |
| 위치 권한 허용     | 사용자가 현재 위치 접근 권한을 허용해야 한다.                        |
| 목적지 검색 가능   | 사용자가 목적지명 또는 주소를 입력할 수 있어야 한다.                 |
| 주차장 데이터 존재 | 목적지 주변의 주차장 정보가 시스템에 등록되어 있어야 한다.           |
| 혼잡도 데이터 존재 | 시스템이 혼잡도 예측에 사용할 기본 데이터 또는 규칙을 보유해야 한다. |

---

## 5.4 기본 흐름

| 단계 | 사용자 행동                                            | 시스템 반응                                                             |
| ---- | ------------------------------------------------------ | ----------------------------------------------------------------------- |
| 1    | 사용자가 SmartPark 앱을 실행한다.                      | 시스템은 현재 위치를 기준으로 지도 화면을 표시한다.                     |
| 2    | 사용자가 목적지 검색창에 “성수동 카페거리”를 입력한다. | 시스템은 검색 결과 목록을 표시한다.                                     |
| 3    | 사용자가 목적지를 선택한다.                            | 시스템은 목적지 주변 주차장 목록과 지도 마커를 표시한다.                |
| 4    | 사용자가 주차장 목록을 확인한다.                       | 시스템은 거리, 요금, 운영 시간, 이용 가능 여부, 혼잡도를 함께 표시한다. |
| 5    | 사용자가 혼잡도가 낮은 주차장을 선택한다.              | 시스템은 주차장 상세 화면을 표시한다.                                   |
| 6    | 사용자가 “경로 안내” 버튼을 선택한다.                  | 시스템은 선택한 주차장까지의 경로를 지도에 표시한다.                    |
| 7    | 사용자가 주차장으로 이동한다.                          | 시스템은 이동 중에도 주차장 상태 변화를 갱신한다.                       |
| 8    | 사용자가 주차장에 도착한다.                            | 시스템은 NFC 이용 시작 또는 입차 확인을 안내한다.                       |

# 6. SS-02 병원 예약 시간에 맞춘 주차장 사전 탐색

## 6.1 시나리오 개요

| 항목          | 내용                                                                                     |
| ------------- | ---------------------------------------------------------------------------------------- |
| 시나리오 ID   | SS-02                                                                                    |
| 시나리오명    | 병원 예약 시간에 맞춘 주차장 사전 탐색                                                   |
| 주요 Actor    | 일정 기반 방문 운전자                                                                    |
| 관련 페르소나 | 박지현                                                                                   |
| 목적          | 병원 예약 시간에 늦지 않도록 도착 예정 시간 기준으로 주차 가능성이 높은 주차장을 찾는다. |
| 핵심 기능     | 도착 예정 시간 입력, AI 혼잡도 예측, 대체 주차장 추천                                    |

---

## 6.2 상황 설명

박지현은 오전 10시에 병원 진료 예약이 있다. 병원 주차장은 평소 혼잡하기 때문에, 도착 후 주차장을 찾기 시작하면 예약 시간에 늦을 수 있다.

박지현은 SmartPark에서 병원을 목적지로 입력하고, 예상 도착 시간을 오전 9시 45분으로 설정한다. 시스템은 해당 시간대의 주차장 혼잡도를 예측하고, 병원까지 도보 이동이 가능한 주차장을 추천한다.

---

## 6.3 사전 조건

| 조건                      | 설명                                                   |
| ------------------------- | ------------------------------------------------------ |
| 목적지 검색 가능          | 병원명 또는 주소를 검색할 수 있어야 한다.              |
| 도착 예정 시간 입력 가능  | 사용자가 예상 도착 시간을 입력할 수 있어야 한다.       |
| 시간대별 혼잡도 예측 가능 | 시스템은 시간대 기반 혼잡도 예측 정보를 제공해야 한다. |
| 도보 거리 계산 가능       | 주차장과 목적지 간 도보 거리 정보가 제공되어야 한다.   |

## 6.4 기본 흐름

| 단계 | 사용자 행동                           | 시스템 반응                                                          |
| ---- | ------------------------------------- | -------------------------------------------------------------------- |
| 1    | 사용자가 병원명을 검색한다.           | 시스템은 검색 결과를 표시한다.                                       |
| 2    | 사용자가 병원을 목적지로 선택한다.    | 시스템은 병원 주변 주차장 목록을 표시한다.                           |
| 3    | 사용자가 도착 예정 시간을 입력한다.   | 시스템은 해당 시간 기준 예상 혼잡도를 계산한다.                      |
| 4    | 사용자가 추천 주차장 목록을 확인한다. | 시스템은 주차 가능성, 도보 거리, 요금 기준으로 추천 순위를 표시한다. |

김민준은 주차 이용 후 NFC로 출차 처리를 하고 결제를 진행했다. 그러나 결제 승인 과정에서 네트워크 오류가 발생하여 결제 상태가 명확하지 않다. 사용자는 결제가 완료되었는지 확인하고 싶고, 운영 관리자는 결제 오류 상태를 확인해 문제를 처리해야 한다.

| 결제 요청 발생   | 결제 API를 통한 결제 요청이 발생해야 한다.                          |
| 관리자 접근 가능 | 운영 관리자가 결제 관리 화면에서 오류 상태를 확인할 수 있어야 한다. |

## 13.2 상황 설명

SmartPark 서비스 이용자가 증가하면서 주차장별 이용 시간, 출차 예정 시간, 실제 이용 가능 여부, 결제 내역, 신고 내역이 축적된다. 시스템은 이 데이터를 기반으로 시간대별 혼잡도를 분석하고, 사용자가 목적지와 도착 예정 시간을 입력했을 때 더 정확한 추천 결과를 제공한다.

운영 관리자는 관리자 대시보드에서 혼잡도 예측 결과와 실제 이용 결과의 차이를 확인하고, 반복적으로 예측이 빗나가는 지역이나 주차장을 검토한다.

| 결제           | 이용 시간 기반 요금 계산 및 결제 기능                   |
| 공급자         | 주차 공간 등록, 시간/요금 설정, 정산 확인 기능          |
| 관리자         | 등록 승인, 신고 처리, 결제 오류 관리, 운영 통계 기능    |

# 18. 정리

SmartPark의 서비스 시나리오는 이용자, 공급자, 관리자 관점에서 구성된다.

일반 이용자는 현재 위치 또는 목적지를 기반으로 주차장을 검색하고, AI 혼잡도와 곧 비워질 자리 정보를 참고하여 실제 주차 가능성이 높은 공간을 선택한다. 주차장 도착 후에는 NFC를 통해 이용 시작과 종료를 처리하고, 이용 시간에 따라 요금을 결제한다.

공급자는 개인 또는 상가의 유휴 주차 공간을 등록하고, 이용 가능 시간과 요금을 설정하여 수익화할 수 있다. 관리자는 신규 주차장 등록을 승인하고, 신고와 결제 오류를 처리하며, 운영 통계를 통해 서비스 품질을 관리한다.

따라서 SmartPark는 단순 주차장 검색 서비스가 아니라, 주차 탐색, 예측 추천, 공유 주차, NFC 결제, 운영 관리를 하나의 흐름으로 연결하는 스마트 주차 플랫폼으로 설계되어야 한다.
