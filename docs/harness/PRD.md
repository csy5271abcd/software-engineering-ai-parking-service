## 1. 문서 개요

### 1.1 문서 목적

본 문서는 SmartPark 서비스의 제품 요구사항을 정의하기 위해 작성되었다.

SmartPark는 도심 및 주거 지역의 주차난 문제를 해결하기 위한 AI 기반 스마트 주차 플랫폼이다. 사용자의 현재 위치와 목적지를 기반으로 주변 주차 가능 공간을 탐색하고, 곧 비워질 주차 공간 정보, 개인 주차장 공유, NFC 기반 간편 결제, AI 기반 혼잡도 분석 기능을 제공한다.

본 문서는 Claude Code, Codex 등 AI 개발 도구가 SmartPark 프로젝트를 일관성 있게 이해하고 작업할 수 있도록 제공하는 하네스 문서이다. 따라서 단순한 서비스 소개가 아니라, 제품의 목표, 사용자, 핵심 기능, MVP 범위, 화면 범위, 데이터 범위, 우선순위, 개발 기준을 명확하게 정리하는 것을 목적으로 한다.

```text
AI 기반 주차난 해결 서비스
```

---

### 2.3 제품 정의

SmartPark는 주차 공간을 찾는 이용자와 유휴 주차 공간을 보유한 공급자를 연결하는 AI 기반 스마트 주차 플랫폼이다.

사용자는 현재 위치 또는 목적지를 기준으로 주변 주차장을 확인할 수 있으며, 주차장의 거리, 요금, 운영 시간, 이용 가능 여부, 예상 혼잡도를 비교할 수 있다. 또한 현재 빈자리뿐 아니라 곧 비워질 자리 정보를 확인하여 실제 주차 성공 가능성이 높은 공간을 선택할 수 있다.

공급자는 개인 주차 공간 또는 상가/건물 주차장을 등록하고, 이용 가능 시간과 요금을 설정하여 유휴 공간을 수익화할 수 있다. 운영 관리자는 등록 승인, 신고 처리, 결제 오류, 운영 통계 등을 관리한다.

---

### 2.4 제품 한 줄 설명

```text
현재 위치와 목적지 기준으로 주차 가능성이 높은 공간을 추천하고, 개인 공유 주차장과 NFC 결제까지 연결하는 AI 기반 스마트 주차 서비스
```

## 3. 문제 정의

### 3.1 사용자 문제

도심, 대학가, 병원, 상가, 행사장 주변에서는 주차 수요가 높지만 주차 공간은 제한적이다. 사용자는 지도 앱에서 주차장 위치를 확인할 수는 있지만, 실제로 도착했을 때 주차가 가능한지는 알기 어렵다. 이로 인해 만차 주차장을 반복적으로 이동하거나, 약속 및 예약 시간에 늦는 문제가 발생한다.

---

### 3.2 공급자 문제

개인 주택, 빌라, 소규모 건물, 상가에는 특정 시간대에 사용되지 않는 유휴 주차 공간이 존재한다. 그러나 개인이 직접 주차 공간을 공유하려면 이용자 모집, 결제, 이용 시간 관리, 분쟁 대응이 필요하기 때문에 부담이 크다.

---

### 3.3 운영자 문제

공유 주차 플랫폼은 주차장 등록 정보의 정확성, 허위 등록, 허위 출차 예정 정보, 결제 오류, 사용자 신고, 개인정보 보호 문제를 관리해야 한다. 운영 관리 기능이 부족하면 서비스 신뢰도가 낮아질 수 있다.

## 7. MVP 범위

### 7.1 MVP 목표

SmartPark MVP는 전체 확장 기능을 모두 구현하기보다, 사용자가 현재 위치 또는 목적지를 기준으로 주차장을 탐색하고, 실제 주차 가능성이 높은 공간을 판단할 수 있는 흐름을 먼저 검증하는 것을 목표로 한다.

초기 구현은 다음 흐름을 기준으로 한다.

```text
앱 실행
→ 현재 위치 기반 지도 표시
→ 주변 주차장 마커 표시
→ 하단 바텀시트에서 주차장 목록 확인
→ 주차장 상세 확인
→ 혼잡도/예상 가능성 확인
→ 경로 안내 버튼 제공
```

---

### 7.2 1차 MVP 포함 기능

| 기능 ID | 기능명 | 포함 여부 | 설명 |
| ------- | ------ | --------- | ---- |
| F01 | 현재 위치 기반 주변 주차장 조회 | 포함 | 현재 위치를 기준으로 주변 주차장을 지도와 목록에 표시 |
| F02 | 목적지 기반 주차장 검색 | 포함 | 목적지 주변 주차장 목록 제공 |
| F03 | 주차장 상세 정보 확인 | 포함 | 거리, 요금, 운영 시간, 혼잡도, 이용 가능 여부 표시 |
| F04 | 곧 비워질 자리 안내 | 부분 포함 | 실제 실시간 데이터 대신 Mock 상태 또는 규칙 기반 데이터로 표시 |
| F08 | AI/규칙 기반 혼잡도 표시 | 포함 | 초기에는 규칙 기반, 이후 Mock 데이터 기반 ML 모델로 확장 |
| 지도/검색 UI | 포함 | NaverMaps 스타일 SearchBar, Chip, BottomSheet, Marker UI 적용 |

## 18. 정리

SmartPark는 단순 주차장 검색 서비스가 아니라, 주차 공간 탐색, 주차 가능성 예측, 개인 주차 공간 공유, NFC 기반 이용 기록, 결제 및 정산, 관리자 운영 기능을 통합한 스마트 주차 플랫폼이다.

본 PRD는 SmartPark의 제품 목표와 MVP 범위, 핵심 기능, 화면 요구사항, 데이터 요구사항, 비기능 요구사항, AI 개발 도구 활용 기준을 정의한다. 이후 `FEATURE_SPEC.md`, `SCREEN_STRUCTURE.md`, `PROJECT_RULES.md`, `CLAUDE.md`, `CODEX.md`, `PROMPT_LOG.md`는 본 문서를 기준으로 세부 내용을 확장한다.
