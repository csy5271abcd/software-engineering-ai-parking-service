# SmartPark 기능 명세서

## 1. 문서 개요

### 1.1 문서 목적

본 문서는 SmartPark의 주요 기능을 개발 가능한 단위로 분해하고, 각 기능의 상세 동작, 입력값, 출력값, 예외 상황, 화면 연결, API 후보를 정리하기 위해 작성되었다.

SmartPark는 사용자의 현재 위치와 목적지를 기반으로 주변 주차 가능 공간을 탐색하고, 곧 비워질 주차 공간 정보, 개인 주차장 공유, NFC 기반 간편 결제, AI 기반 혼잡도 분석 기능을 제공하는 AI 기반 스마트 주차 플랫폼이다.

본 문서는 `PRD.md`에서 정의한 제품 요구사항을 기능 단위로 구체화한 문서이며, Claude Code와 Codex가 각각 프론트엔드와 백엔드 작업을 수행할 때 기준으로 활용한다.

# 4. F-01 현재 위치 기반 주변 주차장 조회

## 4.1 기능 개요

| 항목        | 내용                                                             |
| ----------- | ---------------------------------------------------------------- |
| 기능 ID     | F-01                                                             |
| 기능명      | 현재 위치 기반 주변 주차장 조회                                  |
| 목적        | 사용자가 현재 위치 주변의 주차장을 빠르게 확인할 수 있도록 한다. |
| 주요 사용자 | 일반 운전자                                                      |
| 우선순위    | 높음                                                             |
| 관련 화면   | 메인 지도 화면, 주차장 목록 화면                                 |
| 관련 데이터 | UserLocation, ParkingLot, ParkingSpace, CongestionPrediction     |

---

## 4.2 사전 조건

| 조건          | 설명                                                          |
| ------------- | ------------------------------------------------------------- |
| 위치 권한     | 사용자가 위치 권한을 허용해야 한다.                           |
| 네트워크 연결 | 지도 및 주차장 데이터를 조회할 수 있어야 한다.                |
| 주차장 데이터 | 사용자의 현재 위치 주변에 등록된 주차장 데이터가 있어야 한다. |

---

## 4.3 입력값

| 입력값    | 타입   | 필수 여부 | 설명                                   |
| --------- | ------ | --------- | -------------------------------------- |
| latitude  | number | 필수      | 사용자 현재 위도                       |
| longitude | number | 필수      | 사용자 현재 경도                       |
| radius    | number | 선택      | 검색 반경, 기본값 1km                  |
| sort      | string | 선택      | 정렬 기준: 거리, 요금, 혼잡도          |
| filter    | object | 선택      | 이용 가능 여부, 요금 범위, 주차장 유형 |

---

## 4.4 출력값

| 출력값          | 타입   | 설명                 |
| --------------- | ------ | -------------------- |
| parkingLots     | array  | 주변 주차장 목록     |
| parkingLotId    | number | 주차장 ID            |
| name            | string | 주차장명             |
| distance        | number | 현재 위치로부터 거리 |
| pricePerHour    | number | 시간당 요금          |
| availableCount  | number | 이용 가능 공간 수    |
| status          | string | 주차장 상태          |
| congestionLevel | string | 예상 혼잡도          |
| markerType      | string | 지도 마커 표시 유형  |

---

## 4.5 기본 동작 흐름

```text
앱 실행
→ 위치 권한 확인
→ 현재 위치 좌표 수집
→ 주변 주차장 API 요청
→ 지도 마커 표시
→ 하단 목록 또는 바텀시트에 주차장 카드 표시
```

---

## 4.6 예외 상황

| 예외 상황        | 처리 방식                                         |
| ---------------- | ------------------------------------------------- |
| 위치 권한 거부   | 위치 권한 안내 화면 표시, 수동 위치 입력 제공     |
| 주변 주차장 없음 | 검색 반경 확대 버튼 제공                          |
| 지도 API 오류    | 목록형 결과를 우선 표시하고 지도 재시도 버튼 제공 |
| 네트워크 오류    | 오류 메시지와 재시도 버튼 제공                    |

---

## 4.7 API 후보

```text
GET /api/parking-lots/nearby
```

| Query Parameter | 설명             |
| --------------- | ---------------- |
| lat             | 위도             |
| lng             | 경도             |
| radius          | 검색 반경        |
| sort            | 정렬 기준        |
| status          | 주차장 상태 필터 |

---

## 4.8 완료 기준

| 기준  | 설명                                                            |
| ----- | --------------------------------------------------------------- |
| AC-01 | 위치 권한 허용 시 현재 위치 기준 주차장 목록이 표시되어야 한다. |
| AC-02 | 지도 마커와 목록 카드가 같은 주차장 데이터를 표시해야 한다.     |
| AC-03 | 주차장 카드에는 거리, 요금, 상태, 혼잡도가 표시되어야 한다.     |
| AC-04 | 위치 권한 거부 시 대체 흐름이 제공되어야 한다.                  |

# 5. F-02 목적지 기반 주차장 검색

## 5.1 기능 개요

| 항목        | 내용                                                          |
| ----------- | ------------------------------------------------------------- |
| 기능 ID     | F-02                                                          |
| 기능명      | 목적지 기반 주차장 검색                                       |
| 목적        | 사용자가 목적지 주변의 주차장을 사전에 탐색할 수 있도록 한다. |
| 주요 사용자 | 일반 운전자, 일정 기반 방문 운전자                            |
| 우선순위    | 높음                                                          |
| 관련 화면   | 목적지 검색 화면, 추천 주차장 화면                            |
| 관련 데이터 | Destination, ParkingLot, RouteInfo, CongestionPrediction      |

---

## 5.2 입력값

| 입력값      | 타입     | 필수 여부 | 설명                          |
| ----------- | -------- | --------- | ----------------------------- |
| keyword     | string   | 필수      | 목적지명 또는 주소            |
| arrivalTime | datetime | 선택      | 도착 예정 시간                |
| radius      | number   | 선택      | 목적지 기준 검색 반경         |
| sort        | string   | 선택      | 추천, 거리, 요금, 혼잡도 정렬 |

---

## 5.3 출력값

| 출력값              | 타입   | 설명                         |
| ------------------- | ------ | ---------------------------- |
| destination         | object | 선택된 목적지 정보           |
| parkingLots         | array  | 목적지 주변 주차장 목록      |
| walkingDistance     | number | 주차장과 목적지 간 도보 거리 |
| estimatedCongestion | string | 도착 예정 시간 기준 혼잡도   |
| recommendationScore | number | 추천 점수                    |

---

## 5.4 기본 동작 흐름

```text
사용자가 목적지 검색
→ 시스템이 장소 검색 결과 표시
→ 사용자가 목적지 선택
→ 목적지 좌표 기준 주변 주차장 조회
→ 도착 예정 시간이 있으면 혼잡도 예측 반영
→ 추천 순위에 따라 주차장 목록 표시
```

---

## 5.5 예외 상황

| 예외 상황             | 처리 방식                                   |
| --------------------- | ------------------------------------------- |
| 검색 결과 없음        | 주소 직접 입력 또는 지도에서 위치 선택 제공 |
| 도착 예정 시간 없음   | 현재 시간 기준으로 기본 추천 제공           |
| 목적지 좌표 변환 실패 | 검색어 수정 안내                            |
| 주차장 없음           | 검색 반경 확대 제안                         |

---

# 20. 개발 도구별 적용 지침

## 20.1 Claude Code 적용 지침

Claude Code는 본 문서를 기준으로 React Native 화면과 컴포넌트를 구현한다.

| 기준          | 설명                                                          |
| ------------- | ------------------------------------------------------------- |
| 화면 우선순위 | 메인 지도, 검색, 목록, 상세, 공급자 등록 화면을 우선 구현     |
| 컴포넌트 분리 | 주차장 카드, 혼잡도 배지, 상태 배지, 버튼, 바텀시트 분리      |
| 상태 표시     | 주차 공간 상태와 결제 상태를 명확한 배지로 표시               |
| 예외 화면     | 위치 권한 거부, 검색 결과 없음, NFC 실패, 결제 실패 화면 포함 |
| API 연동      | `services/` 폴더에 API 호출 함수 분리                         |

---

## 20.2 Codex 적용 지침

Codex는 본 문서를 기준으로 백엔드 API, DTO, 도메인 모델, 서비스 로직을 설계한다.

| 기준          | 설명                                                        |
| ------------- | ----------------------------------------------------------- |
| 계층 구조     | Controller, Service, Repository, DTO 구조 유지              |
| 도메인 중심   | User, ParkingLot, ParkingSession, Payment, Report 중심 설계 |
| API 명세 우선 | 입력값, 출력값, 예외 상황을 먼저 정리                       |
| 상태값 관리   | 주차, 결제, 신고, 승인 상태는 enum으로 관리                 |
| 테스트 가능성 | 핵심 서비스 로직은 단위 테스트가 가능하도록 분리            |

# 21. 정리

본 기능 명세서는 SmartPark의 주요 기능을 개발 가능한 단위로 정리한 문서이다.

`PRD.md`가 제품의 목표와 범위를 정의한다면, `FEATURE_SPEC.md`는 각 기능이 실제로 어떤 입력을 받고, 어떤 결과를 반환하며, 어떤 예외 상황을 처리해야 하는지 구체화한다.

이 문서는 이후 `SCREEN_STRUCTURE.md`, `PROJECT_RULES.md`, `CLAUDE.md`, `CODEX.md`, `PROMPT_LOG.md` 작성의 기준이 되며, 요구사항 정의서, 요구사항 분석서, 소프트웨어 설계서, 테스트 결과서와도 연결된다.
